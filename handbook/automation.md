# Validate behaviour, not green decorations

Choose checks that support the project's claims: schema validation for structured rules, tests for detectors, deterministic regeneration for derived exports, and runnable examples where execution can be controlled. A workflow file is configuration, not proof that checks ran or are required before merge.

Keep pull-request checks read-only. Generated changes should be committed intentionally through the normal review path rather than pushed by a broadly privileged documentation job. Dependency maintenance must enumerate all package directories; a root update configuration does not establish coverage for a nested package. In v0.3, `QUAL-004` checks basic npm, pip requirements/pyproject, Cargo, Go modules, Composer, Bundler and GitHub Actions manifests against Dependabot's configured ecosystems and paths. For `github-actions`, the updater directory is `/`. No Dependabot file yields manual review because another updater may exist. Recognised but incomplete config yields a narrow failure. Globs, complex YAML, unreadable manifests and unsupported ecosystems are not treated as covered. The v0.3 `QUAL-004` static check recognises basic npm (only when external dependencies are declared), requirements/pyproject pip, Cargo, go.mod, Composer, Gemfile and GitHub Actions patterns. It compares manifest directories with `dependabot.yml` version 2 entries. `github-actions` must target `/`. Absent Dependabot is manual review because Renovate or an external updater may be used; clear partial coverage in a well-formed checked-in Dependabot configuration is a narrow failure. `directories` is supported for explicit paths; globs, unusual YAML, unsupported ecosystems and unreadable manifests are not silently counted as covered. Disabled update PRs (`open-pull-requests-limit: 0`) do not prove active coverage. No network update job is executed or verified.

The built-in link checker supports simple inline and reference Markdown links, images and ATX heading hints. It skips code fences, inline code and comments. Templates are excluded because they intentionally refer to files in a future target project. External URLs are never fetched. Shortcut references, complex CommonMark, HTML, root-relative targets and unresolved anchors are outside its automatic pass scope or deferred for review. It is not a replacement for a full Markdown parser or Lychee.

Use dedicated tools such as actionlint for full workflow syntax and policy tools for deeper checks. The `SEC-001` static subset only detects clearly mutable `uses` refs, explicit `write-all` grants and obvious privileged-event review triggers. It does not parse general YAML, infer trust boundaries, validate a SHA against its release, detect all shell injection patterns or certify an Action. Keep network-dependent link audits separate from deterministic local validation, with retry limits and an advisory reporting policy. A timeout is not proof of a dead URL.

CI in this repository validates schemas, supported local links, tests, generated freshness, a self-audit and a static explorer build. It deliberately does not publish artifacts or modify repository settings.
