# Participation policy

Be respectful, specific and constructive. Welcome contributors with different backgrounds and experience. Critique changes and claims, not people. Harassment, threats, discrimination, deliberate exposure of private information and repeated disruptive behaviour are not acceptable.

Maintainers may edit or remove harmful content, restrict participation or close discussions, with an explanation when safe and appropriate. Apply moderation consistently and distinguish good-faith technical disagreement from abuse.

For sensitive concerns, use an existing private channel to the repository owner. If no private channel is available, request one without posting personal details or allegations publicly. A dedicated confidential contact route is pending maintainer confirmation; no response-time guarantee is implied.

This original participation policy is intentionally short and is not presented as an unmodified external code of conduct.
