# Template library

Templates are starting points, not required files. Replace every `{{placeholder}}`, remove irrelevant sections and verify copied commands before adoption. They are intentionally excluded from local-link checks because their links refer to the future target repository.

Use the documentation README for a guide, the catalogue README for structured resources, the library README for reusable code, or the application README for a runnable service. Do not force every project to deploy a website or publish a package.

The contribution and security templates need real validation commands and a verified private contact route. The decision template records a trade-off; it should not become an empty architecture folder. The workflow example is specific to a Node project with an existing check command and lockfile: do not copy it into unrelated stacks.
